PERSONALIZE THE SCRAPBOOK PHOTOS
================================
Add your own images to this folder with these filenames:

- portrait.jpg  - Portrait shown in the birthday hero section
- photo1.webp   - Gallery memory 1 (birthday celebration)
- photo2.webp   - Gallery memory 2 (moment)
- photo3.webp   - Gallery memory 3 (sunset)
- photo4.webp   - Gallery memory 4 (celebration)
- photo5.webp   - Gallery memory 5 (moment)
- photo6.jpg    - Gallery memory 6 (moment)
- photo7.jpg    - Gallery memory 7 (sunset)

The gallery has seven photo slots. Images are optional: the site uses bundled
WebP fallback artwork for the portrait and the first five gallery slots, and a
decorative scrapbook placeholder for the remaining empty slots. The portrait
is read from `portrait.jpg` when supplied.

To change gallery captions, categories, or the selected image files, edit the
`gallery.photos` entries in `src/config/birthdayConfig.ts`.
