HOW TO ADD YOUR OWN PHOTOS
==========================
Drop your personal photos into this folder (`public/images/`) using these exact filenames:

- portrait.jpg  -> Hero portrait frame
- photo1.jpg    -> Gallery Memory 1
- photo2.jpg    -> Gallery Memory 2
- photo3.jpg    -> Gallery Memory 3
- photo4.jpg    -> Gallery Memory 4
- photo5.jpg    -> Gallery Memory 5
- photo6.jpg    -> Gallery Memory 6
- photo7.jpg    -> Gallery Memory 7
- photo8.jpg    -> Gallery Memory 8
- photo9.jpg    -> Gallery Memory 9
- photo10.jpg   -> Gallery Memory 10

You can also customize captions, dates, or add even more photos inside `src/config/birthdayConfig.ts`.
Until you upload your own photos, the website displays dreamy fallback keepsakes automatically.
